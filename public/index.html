AIと協業する
ナレッジベース

個人とAIが共同管理する、AIファーストのナレッジベース。
AIが8割書き、人間が読む・編集する。MCPでClaude等から直接読み書きできる。

はじめる 機能を見る

何ができるか

  • Web UI — ツリー状のコレクション・ドキュメント管理。Markdownで書いてサーバー側でHTMLレンダリング
  • MCPプロトコル — Claude Desktop・Claude Code等のAIツールから直接ドキュメントを読み書き
  • APIキー — AI向けの読み取り専用・読み書き権限を発行。コレクション単位でスコープ制限
  • 受信箱 — 外部からトークン経由でテキストを投稿。承認後にドキュメントに追記
  • リビジョン管理 — 全変更履歴を記録。AIが書いたか人間が書いたかを署名で追跡
  • リンク同期 — [[doc_xxx]]記法でドキュメント間リンクを自動管理

設計のポイント

  • AIファースト — AIの探索コストを下げる設計。APIキー + MCPでAIが直接アクセス
  • サーバーレス — Cloudflare Workers + D1 + R2。安く・速く・スケールする
  • HTMX — SPA不要。軽量なサーバー側レンダリングでモバイルも快適
  • マルチテナント — ユーザーごとにデータが分離。Clerkで認証
Cloudflare Workers D1 (SQLite) R2 Clerk Hono HTMX MCP OAuth 2.1

使い方

  • 人間 — Web UIでコレクションを作り、ドキュメントを書く・読む・編集する
  • AI — APIキーを発行してClaude Code等に設定。MCP経由でナレッジベースを読み書き
  • 協業 — AIがドキュメントを書き、人間が確認・編集。変更履歴で誰が書いたか追跡
